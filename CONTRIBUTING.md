# Contributing

Contributions need a Developer Certificate of Origin sign-off: add `Signed-off-by: Your Name <you@example.com>` to each commit (`git commit -s`). By signing off you confirm you have the right to submit the work under this repository's licence (https://developercertificate.org).

Issues and pull requests are welcome. Keep changes small, and say what they fix.

The files in `lib/` are byte-identical copies of the referee's own modules, which is what makes this verifier trustworthy. Please do not change them here; report what you found instead.
